CrystalBase.KPath — Type
struct KPath{T<:Real}

A k-point path in the Brillouin zone, stored as polylines, one per Subpath.

Vertices within a subpath are connected; consecutive subpaths are separated by a discontinuity. The dense k-point list (kpoints), the cumulative plot axis (axis) and the high-symmetry ticks (tick_indices, tick_labels) are derived on access.

Fields

  • recip_lattice: reciprocal lattice, 3 × 3, each column is a reciprocal lattice vector (Å⁻¹)

  • subpaths: connected pieces of the path

CrystalBase.KPath — Method
KPath(recip_lattice, kpoint_path; n_points_first_segment = 100)

Construct the polylines of a wannier90-style kpoint_path: a vector of two-point segments, each a pair of label => fractional coordinate, as returned for the kpoint_path block by WannierIO.read_win:

kpoint_path = [
    [:Γ => [0.0, 0.0, 0.0], :M => [0.5, 0.5, 0.0]],
    [:M => [0.5, 0.5, 0.0], :R => [0.5, 0.5, 0.5]],
]

Consecutive segments are joined into one Subpath when the end of one and the start of the next have the same label and coordinate; otherwise a discontinuity is inserted. Divisions follow wannier90: the first segment gets n_points_first_segment intervals and every other segment the same spacing (see resample), so the result reproduces bands_num_points.

CrystalBase.KPath — Method
KPath(recip_lattice, kpoints, indices, labels; break_tol = 0.0)

Wrap an explicit list of fractional kpoints verbatim, labeling kpoints[indices[i]] with labels[i]. This is the layout of wannier90 band.kpt and band.labelinfo.dat files.

Two labeled points at consecutive indices mark a discontinuity, following the wannier90 convention that a shared corner is written once. break_tol additionally enables the geometric heuristic of the labels-keyword method.

source
CrystalBase.KPath — Method
KPath(recip_lattice, kpoints; labels = fill("", length(kpoints)), break_tol = 3.0)

Wrap an explicit list of fractional kpoints verbatim: every point becomes a vertex, every segment has one division, so kpoints round-trips the input exactly.

labels gives one label per k-point ("" for none). Discontinuities are inferred from the sampling: a step longer than break_tol times the median step starts a new Subpath. Pass break_tol = 0 to disable the heuristic and keep one connected subpath.

CrystalBase.Subpath — Type
struct Subpath{T<:Real}

One connected polyline of a KPath.

Consecutive vertices define segments; divisions[j] is the number of intervals the j-th segment is split into when sampled. A verbatim list of k-points is a subpath whose divisions are all 1.

Fields

  • vertices: fractional k-point coordinates of the vertices, length m ≥ 1

  • labels: one label per vertex; "" marks an unlabeled vertex (no plot tick)

  • divisions: intervals per segment, length m - 1, each ≥ 1

CrystalBase.resample — Method
resample(kpath; n_points_first_segment)
resample(kpath; density)

Return a KPath with the same vertices and labels but new divisions.

  • n_points_first_segment: wannier90 rule. The first segment of the first subpath gets this many intervals; every other segment gets the same spacing, rounded half up, at least 1.
  • density: intervals per unit reciprocal length (Å); each segment gets round(length · density), at least 1.

CrystalBase.tick_indices — Method
tick_indices(kpath; merge = true)

Indices into kpoints of the labeled vertices.

With merge = true two labeled points straddling a discontinuity share one tick, labeled A|B, as a band plot draws them. With merge = false every labeled vertex is its own tick, the layout of wannier90 labelinfo.dat.
